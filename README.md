# 終焉マトリクス編成板

鳴潮（Wuthering Waves）の高難易度コンテンツ「終焉マトリクス」向けのチーム編成シミュレーターです。

**公開ページ:** https://sekiguchi-sechi.github.io/wuwa-matrix/

## できること

- 所持キャラクターを登録し、その中からチームを組む（1チーム3人、チーム数は無制限）
- クリックまたはドラッグ＆ドロップでキャラを配置、チームの並べ替え
- 開催期間（バージョン）ごとの敵情報・クライシス担当・2回出撃可キャラ・増幅回路の確認
- 期間ごとに編成を保存、前の期間からのコピー、1手戻す
- 出撃回数の超過チェック（ヒーラー枠とクライシス担当は2回まで）
- 編成のテキストコピー、画像として保存
- PC・スマホどちらでも利用可（ライト／ダーク切替つき）

編成と所持キャラの情報は、お使いのブラウザ内（localStorage）にのみ保存されます。サーバーには何も送信しません。

## データについて

キャラクター一覧・敵情報は `data.json` にまとめており、鳴潮Wiki* や攻略サイトの情報をもとに更新しています。
「要確認」と表示されている期間は未確認の情報を含むため、ゲーム内の表示を優先してください。

## 構成

```
data.json        マスタデータ（正本）
src/
  index.html     ページ
  style.css      スタイル
  js/*.js        アプリ本体（ファイル名順に連結して docs/app.js になる）
  vendor/        SortableJS 1.15.0, html2canvas 1.4.1（同梱）
assets/img/      キャラ・ボス画像（webp）
build.py         検証とビルド
docs/            生成物。GitHub Pages の公開元（直接編集しない）
```

ビルド:

```bash
python build.py          # data.json を検証して docs/ を生成
python build.py --check  # 検証のみ
```

push すると GitHub Actions が `data.json` の検証と `docs/` の同期を確認します。
