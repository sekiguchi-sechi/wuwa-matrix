# 終焉マトリクス編成板

鳴潮（Wuthering Waves）の高難易度コンテンツ「終焉マトリクス」向けのチーム編成シミュレーターです。

**公開ページ:** https://sekiguchi-sechi.github.io/wuwa-matrix/

## できること

- 所持キャラクターを登録し、その中からチームを組む（1チーム3人、チーム数は無制限）
- クリックまたはドラッグ＆ドロップでキャラを配置、チームの並べ替え
- 開催期間（バージョン）ごとの敵情報・クライシス担当・2回出撃可キャラ・増幅回路の確認
- 期間ごとに編成を保存、前の期間からのコピー
- 出撃回数の超過チェック（ヒーラー枠とクライシス担当は2回まで）
- 編成のテキストコピー、画像として保存
- PC・スマホどちらでも利用可（ダーク／ライト対応）

編成と所持キャラの情報は、お使いのブラウザ内（localStorage）にのみ保存されます。サーバーには何も送信しません。

## データについて

キャラクター一覧・敵情報は `data.json` にまとめており、鳴潮Wiki* や攻略サイトの情報をもとに更新しています。
「要確認」と表示されている期間は未確認の情報を含むため、ゲーム内の表示を優先してください。

## 仕組み

```
data.json + template.html  --(build.py)-->  docs/index.html  --(GitHub Pages)-->  公開ページ
```

- `data.json` … キャラ・期間・敵などのマスタデータ（正本）
- `template.html` … ページのソース
- `build.py` … マスタを埋め込んだ `docs/index.html` を生成し、`web/img/` の画像を `docs/img/` へコピー
- `docs/` … 生成物。直接編集しません

ローカルでビルドする場合:

```bash
python build.py
```
